ดูโครงงาน

ความเป็นมาและความสำคัญ

ทำไมเราจึงสนใจเรื่องนี้

ปัจจุบันการเล่นเกมออนไลน์ได้รับความนิยมอย่างแพร่หลายในกลุ่มนักเรียน ระดับมัธยมศึกษาตอนปลาย นักเรียนใช้เวลาเล่นเกมแตกต่างกัน บางคนเล่นเพื่อผ่อนคลาย ขณะที่บางคนเล่นเป็นเวลานาน ซึ่งอาจส่งผลต่อการเรียน การบริหารเวลา และการพักผ่อน

โครงงานนี้จึงศึกษาว่าเวลาเล่นเกมมีความสัมพันธ์กับผลการเรียนมากน้อยเพียงใด โดยใช้สถิติ การสร้างกราฟ การวิเคราะห์ความสัมพันธ์ ค่าเฉลี่ย ส่วนเบี่ยงเบนมาตรฐาน และสมการเส้นตรง

ใช้ดูการกระจายตัวของข้อมูล

Pearson Correlation

ใช้หาค่า r เพื่อดูความสัมพันธ์และทิศทางระหว่างเวลาเล่นเกมกับ GPA

Linear Regression

สร้างสมการเส้นตรง Y = a + bX เพื่อสร้างแบบจำลองความสัมพันธ์

Scatter Plot

สร้างกราฟกระจายเพื่อช่วยมองเห็นรูปแบบความสัมพันธ์ของข้อมูล

วิธีดำเนินงาน

1. ศึกษาเอกสาร

ศึกษาเอกสารและงานวิจัยที่เกี่ยวข้อง

2. ออกแบบแบบสอบถาม

สร้างคำถามสำหรับเก็บข้อมูลจากนักเรียน

3. เก็บข้อมูล

เก็บข้อมูลจากนักเรียนกลุ่มตัวอย่าง

4. ตรวจสอบข้อมูล

ตรวจสอบความถูกต้องของข้อมูลที่ได้รับ

5. คำนวณและวิเคราะห์

คำนวณสถิติ สร้าง Scatter Plot และวิเคราะห์ความสัมพันธ์

6. สรุปผล

สรุปและอภิปรายผล พร้อมสร้างข้อเสนอแนะ

Y, ตัวแปรตาม

แบบสอบถาม

คำถามที่ใช้เก็บข้อมูล

  1. โดยเฉลี่ยใน 1 วัน รวมวันธรรมดาและเสาร์-อาทิตย์ คุณใช้เวลาเล่นเกมกี่ชั่วโมง
  2. ระบุเกรดเฉลี่ยสะสมล่าสุดของคุณ
  3. ช่วงเวลาที่ท่านมักเล่นเกมและครั้งละนานเท่าไหร่
  4. คุณแบ่งเวลาหรือจัดลำดับความสำคัญระหว่างการเล่นเกม การอ่านหนังสือ และการทำการบ้านอย่างไรในแต่ละวัน
  5. คุณคิดว่าการเล่นเกมส่งผลกระทบต่อผลการเรียน สมาธิ หรือการอ่านหนังสือของคุณอย่างไรบ้าง ทั้งด้านดีและด้านเสีย
